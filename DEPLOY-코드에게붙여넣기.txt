Time Left 앱을 인터넷에 배포해줘. 나는 개발을 모르니까 네가 전부 알아서 하고,
내가 해야 하는 건 로그인 승인 같은 "나 아니면 못 하는 것"만 딱 짚어서 알려줘.
중간에 뭘 고를지 나한테 묻지 말고 네가 판단해서 진행해.

■ 준비물
다운로드 폴더에 time-left-site.zip 이 있어. 없으면 나한테 말해줘.
그 안에 index.html, sw.js, manifest.webmanifest, privacy.html, terms.html,
ads.txt, v/ 폴더(영상 12개), 아이콘들이 들어있어. 빌드 과정은 전혀 필요 없는
완성된 정적 사이트야. 압축만 풀어서 그대로 올리면 돼.

■ 해야 할 일 (순서대로)
1. 작업 폴더를 하나 만들고(예: ~/time-left) zip을 거기에 풀어줘.
   index.html이 폴더 최상단에 오도록. 한 단계 더 들어가 있으면 꺼내줘.

2. 필요한 도구가 없으면 먼저 설치해줘: git, gh(GitHub CLI).
   Windows면 winget, macOS면 brew 써서.

3. GitHub에 배포해줘.
   - gh auth status 로 로그인 상태 확인. 안 돼 있으면 gh auth login --web 실행하고,
     화면에 나오는 8자리 코드와 눌러야 할 버튼을 나한테 딱 한 번만 알려줘.
   - time-left 라는 이름의 공개(public) 레포를 만들어줘.
     이미 있으면 time-left-app 처럼 뒤에 붙여서 만들고 나한테 알려줘.
   - 폴더 전체를 커밋해서 main 브랜치에 푸시해줘.
   - GitHub Pages를 켜줘. 소스는 main 브랜치 / 루트(/).
     gh api -X POST repos/{owner}/time-left/pages -f "source[branch]=main" -f "source[path]=/"
     이런 식으로 CLI로 켜. 나한테 웹에서 클릭하라고 시키지 말고 네가 API로 해줘.
   - 1~2분 기다렸다가 주소가 실제로 열리는지 curl로 확인해줘.
     주소는 https://<내아이디>.github.io/time-left/ 형태야.

4. 열리면 아래 3가지를 반드시 직접 확인하고 결과를 알려줘.
   - 메인 페이지가 200으로 뜨는지
   - v/surgery.webm 같은 영상 파일이 200으로 뜨는지
   - privacy.html 과 terms.html 이 200으로 뜨는지
   하나라도 404면 경로 문제니까 네가 고쳐서 다시 푸시해줘.

5. 주소가 확인되면 폴더 안의 setup.py 를 그 주소로 한 번 실행해줘.
   python3 setup.py https://<확인된주소>
   이게 canonical·og·sitemap·robots 안의 __SITE__ 를 실제 주소로 바꿔줘.
   실행 후 "남은 __SITE__: 없음" 이 나와야 해. 그 다음 다시 커밋·푸시해줘.
   (이걸 빼먹으면 구글이 사이트를 제대로 색인하지 못해. 반드시 해줘.)

6. 마지막으로 다시 한번 주소가 열리는지 확인하고, 최종 주소 한 줄만 크게 알려줘.

■ GitHub이 막히면 (2순위)
Cloudflare Pages로 해줘.
   npm i -g wrangler
   wrangler pages project create time-left --production-branch main
   wrangler pages deploy . --project-name time-left
로그인 창이 뜨면 나한테 알려줘. 여기도 빌드 설정 필요 없어. 그냥 폴더 업로드야.

■ 지켜야 할 것
- index.html 안의 내용은 절대 고치지 마. 완성본이야. 경로도 전부 상대경로로 맞춰놨어.
- 비밀번호나 토큰을 화면이나 파일에 출력하지 마.
- 실패하면 "안 됩니다" 하고 끝내지 말고, 원인을 찾아서 다른 방법으로 다시 시도해줘.
- 다 되면 내가 나중에 또 배포할 수 있게, 이 폴더에서 다시 올리는 방법을
  한 줄 명령어로 정리해서 README에 적어줘.
